# P0 实施拆解

## 目标

优先把产品从“能生成”推进到“能追踪、能恢复、能持续制作”。P0 只处理任务中心、参数确认、画布时间线、Render 节点状态恢复、API key 和历史任务入口。

## 1. 任务中心

### 路由和入口

- 新增 `/tasks` 作为任务中心主入口。
- `/profile` 保留账号信息和 API key 设置，历史任务入口跳转到 `/tasks`。
- 顶部导航、对话制作、专业画布、Task 查询页都增加任务中心入口。

### 后端接口

- `GET /api/tasks`：当前用户任务列表，支持分页、筛选、搜索。
- `GET /api/tasks/:taskId`：任务详情，兼容本地 Task ID 和上游 Task ID。
- `POST /api/tasks/:taskId/refresh`：强制拉取上游结果。
- `POST /api/tasks/batch-refresh`：批量刷新运行中 / 失败任务。
- `GET /api/tasks/export.csv`：导出筛选后的 CSV。

### 列表字段

- 本地 Task ID
- 上游 Task ID
- 项目名
- 来源
- 状态
- 进度
- 创建时间
- 更新时间
- 完成时间
- 视频缩略预览
- 视频 URL / Result URL
- 失败原因摘要

### 交互

- 左侧高密度列表，右侧详情抽屉。
- 点击行打开详情抽屉，不跳页。
- 详情抽屉展示视频、完整 ID、参数、错误事件、上游原始结果、恢复操作。
- 失败任务根据错误类型展示推荐动作。

## 2. 参数确认卡

### 共用组件

- 新增 `GenerationConfirmCard`，对话生成和画布生成共用。
- 支持紧凑模式和抽屉 / 弹窗模式。

### 展示字段

- Prompt
- Negative Prompt
- 模型
- 时长
- 比例
- 分辨率
- 参考图
- 首帧
- 尾帧
- 镜头运动
- 运动强度
- 是否生成音频
- 是否水印

### 流程

- 第一步：解析创意，产出可编辑参数。
- 第二步：确认参数，提交生成。
- 提交后立即创建本地 Task 卡，即使上游提交失败也保留本地错误记录。
- 只要已有上游 Task ID，失败状态也必须允许继续刷新结果。

## 3. 画布底部时间线

### 基础行为

- 无已完成片段时默认隐藏。
- 有内容时默认收起，只露出片段数量、播放整条链、展开按钮。
- 展开后展示片段顺序和视频预览。
- 不能遮挡画布核心节点操作。

### 操作

- 播放整条链。
- 复制全部视频 URL。
- 选中片段时定位到对应 Render 节点。
- 支持后续扩展拖拽排序。

## 4. Render 节点状态恢复

### 节点展示

- 直接展示本地 Task ID 和上游 Task ID。
- 展示任务状态、进度、更新时间。
- 已完成展示视频预览。
- 失败展示原因摘要和推荐动作。

### 节点操作

- 复制本地 Task ID。
- 复制上游 Task ID。
- 重新拉取结果。
- 打开 Task 查询。
- 打开错误事件。
- 续写下一段。

### 异常恢复原则

- 提交失败：没有上游 Task ID，提示用户修改参数或 API key 后重试。
- 生成失败：有上游 Task ID，允许继续刷新并显示上游错误。
- 本地同步失败：有上游 Task ID，优先通过上游 Task ID 恢复视频结果。

## 5. API key 和个人信息

### 已有能力保留

- 个人信息页修改 API key。
- API key 加密保存。
- API key 提示用户通过 bobAPI 获取，并选择包含 Seedance 模型的分组，例如：banana Pro 官转。

### P0 优化

- API key 错误时，任务中心和 Render 节点都提供“去修改 API key”入口。
- 测试 key 创建的任务也进入任务中心，并标记来源为测试任务。

## 验收清单

- 用户可以在 10 秒内通过 Task ID 搜到历史任务。
- 每次生成前都有参数确认。
- 每次提交后都能看到本地 Task ID。
- 失败任务有错误原因和下一步操作。
- 有上游 Task ID 的失败任务可以继续重新拉取结果。
- Render 节点直接可见 Task ID、状态、重新拉取入口。
- 底部时间线收起时不遮挡画布。
- 已完成视频可以在任务中心、Task 查询页、Render 节点直接播放。
